# HR-DATA-ANALYTICS
HR Data Analysis &amp; Dashboard
This project analyzes HR data using Python and Microsoft Excel to uncover meaningful insights about employee demographics, job roles, salaries, departments, performance, and workforce trends.
Python is used for data cleaning, preprocessing, and exploratory data analysis (EDA), while Excel is used to build an interactive HR dashboard with charts, PivotTables, KPIs, and slicers for easy exploration of the data.
Key Highlights
Data cleaning and preprocessing using Python
Exploratory Data Analysis (EDA)
Employee demographic and workforce analysis
Department, job role, salary, and experience analysis
Excel PivotTables and PivotCharts
Interactive dashboard with KPIs and slicers
Visualization of important HR trends and insights
Tools & Technologies
Python | Pandas | NumPy | Matplotlib | Seaborn | Jupyter Notebook | Microsoft Excel
This project demonstrates practical Data Analytics skills, combining Python-based analysis with an interactive Excel dashboard to transform raw HR data into clear, actionable business insights.
